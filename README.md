# CrosshairWlorx

**CrosshairWlorx** — это бесплатная программа для создания и использования собственных прицелов в любых играх. Больше не нужно платить за подписки — настраивайте прицел под себя и побеждайте!

## ✨ Особенности
- **Полностью бесплатно** — никаких скрытых платежей и подписок.
- **Работает в любых играх** — от шутеров до инди-проектов.
- **Гибкая настройка** — цвет, форма, размер, прозрачность и другие параметры (если это реализовано).
- **Простой запуск** — не требует установки.

## 🚀 Как начать пользоваться
1. Скачайте последнюю версию `main.exe` из раздела [Releases](https://github.com/WlorxStudio/CrosshairWlorx/releases) (или прямо из репозитория).
2. Запустите файл.
3. Настройте прицел под свои предпочтения.
4. Играйте и побеждайте!

> **Важно:** программа может требовать прав администратора для наложения поверх игр.
